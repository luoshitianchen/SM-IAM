# SM-IAM 容灾演练手册（DR Runbook）

> 版本 v1.0 ｜ 服务：SM-IAM（sm-iam，端口 8001）｜ 数据库：sm_iam
> RTO 目标 ≤ 10 分钟，RPO 目标 ≤ 5 分钟（依赖 WAL 归档）。

## 1. 数据库备份恢复

- 备份策略：每日全量 + 实时 WAL 归档至对象存储（跨可用区）。
- 恢复步骤：
  1. 在备用可用区拉起 PostgreSQL 新实例。
  2. 恢复最近全量备份，重放 WAL 至目标时间点。
  3. 更新 SM_DATABASE_HOST / SM_DATABASE_URL（Vault），重启 Pod。
  4. 验证连接与业务一致性。

## 2. 服务降级方案

- 非核心接口（报表、通知）优先降级，保障核心读写。
- 开关：通过配置中心关闭非必要依赖调用，返回缓存/默认值。
- 限流：在 API-Gateway 与服务层启用限流，保护后端数据库。

## 3. 跨可用区 / 跨区域切换

1. 确认主可用区故障范围与影响。
2. 将 DNS / Ingress 流量切至备用可用区（Pod 已跨区调度）。
3. 提升备库为主库，更新连接串。
4. 验证业务与监控，发布状态公告。
5. 主区恢复后按计划回切。

## 4. 演练频率与记录

- 每季度一次切换演练，每半年一次完整容灾演练。
- 演练记录：时间、范围、RTO/RPO 实测、问题项、改进项。
- 演练结果纳入服务健康度与 CAB 评审输入。
